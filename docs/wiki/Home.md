# Host-Tools

Host-Tools is a classic AmigaOS 68k package for [Amiberry](https://github.com/BlitterStudio/amiberry). It provides 11 commands that connect the Amiga to its Linux, macOS, or Windows host, two AHI audio drivers, and an MHI MP3 decoder.

- [Getting started](Getting-Started): requirements, host support, installation, and examples.
- [Command tools](Command-Tools): syntax and host behavior for all 11 commands.
- [Audio and MP3](Audio-and-MP3): AHI modes, the UAESND sound board, and MHI decoding.

For an offline reference, install the `Host-Tools.guide` AmigaGuide from the release archive. The [README](https://github.com/BlitterStudio/host-tools#readme) has the package summary and build instructions. These wiki pages are published from `docs/wiki/` in the source repository; edit that versioned source alongside implementation changes rather than editing the published copy separately.
